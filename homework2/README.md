# 一箭又一箭

这是一个基于 Python Tkinter 的网格箭头解谜小游戏，按照本项目的 [PRD](PRD.md) 实现。玩家需要观察箭头方向和前方阻挡关系，按正确顺序点击箭头，使它们飞出棋盘。

## 功能

- 支持上、下、左、右四个方向的单格箭头。
- 沿箭头前进方向逐格扫描到棋盘边界，准确判断是否被阻挡。
- 无阻挡时播放飞出动画并移除箭头。
- 被阻挡时显示红色碰撞反馈并扣除一次失误机会。
- 4 个难度递增的随机棋盘；每次开始或重开都会生成新布局，并通过逆向构造保证可解。
- 完整的开始、游戏中、通关、失败和全部通关流程。
- 支持重新开始当前关卡和返回首页。

## 运行环境

- Python 3.10 或更高版本
- Windows 桌面环境
- 仅使用 Python 标准库，GUI 使用 Tkinter，不需要联网或额外服务

## 运行

在仓库根目录执行：

```powershell
python -m homework2
```

如果系统没有把 Python 加入 PATH，请使用本机 Python 解释器的完整路径运行同一条命令。

## 自动化测试

项目使用标准库 `unittest`，不需要安装 pytest：

```powershell
python -m unittest discover -s homework2/tests -v
```

测试覆盖：

- 四方向路径扫描和边界保护；
- 前方阻挡、后方不阻挡和空格点击；
- 固定关卡模板和随机棋盘的可解性；
- 随机布局的尺寸、箭头数量继承和重开刷新；
- 消除、碰撞扣分、失误耗尽；
- 通关、下一关、全部通关；
- 重新开始恢复棋盘和失误次数；
- 非法关卡数据校验。

## 操作说明

1. 点击“开始游戏”进入第 1 关。
2. 点击前方没有其他箭头的箭头，箭头会飞出并消失。
3. 点击被挡住的箭头会触发碰撞反馈，并消耗一次失误机会。
4. 清空当前棋盘后点击“下一关”；失误机会耗尽后点击“重新开始”。

## 开发验证

关卡数据与规则层相互独立。固定模板和随机生成的棋盘都会在测试中由记忆化 DFS 求解器验证存在完整消除顺序；随机生成器本身还通过逆向构造保留一条合法消除顺序，避免出现“看起来合理但实际无解”的死局。AIGC 生成或建议的实现需要经过自动化测试和实际运行检查后才能进入项目。
